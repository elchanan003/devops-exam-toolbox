# Surface: home (src/content/docs/index.mdx) + site-wide reading styles (src/styles/custom.css)

Mode: Read (docs index) with Operate density. Audience: one student mid-exam, second monitor, scanning.
Job: reach the right page in two clicks or Ctrl+K. Constraint: Starlight chrome stays (sidebar, search, pager).

## Direction contract
THESIS: The home page is a book's back index, not a landing page: every tab with its most-used tasks as direct deep links, set typographically. Refuses the category default of hero + same-size icon cards.
OWN-WORLD: The user's guide family: green-tinted neutrals (ground #f3f5f3 / ink #14201b; dark #0d1310 / #e4ece7), one teal accent (#0c6b5b / #41c4aa) for links and current state only, Heebo body, Rubik headings, JetBrains Mono strictly for code; hairline rules instead of boxes; amber placeholder chips; callouts as tinted fields with a 1px rule, no thick side bars.
STORY: The visitor sees the whole toolbox at once, recognises their task by its English term, clicks, copies, returns to the terminal.
FIRST VIEWPORT: Title + one-line purpose and a Ctrl+K hint at top; a single row of four first-aid links (symptom table, where-does-this-run, full scripts, verification ladder); below, a two-column index of tab blocks (tab name as heading link, hairline, 4–6 task links each) filling the rest of the viewport.
FORM: Dense tab index; position 3 on the ranked list; seed key dfd6f7d7.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
